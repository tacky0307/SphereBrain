# Sphere Brain

**Sphere Brain** is an experimental research project exploring a new AI architecture based on a spherical neural network.

Unlike conventional neural networks that mainly focus on node activations, Sphere Brain explores the hypothesis that **the paths taken by signals through the network are themselves a form of memory**.

## Vision

The long-term goal is to build an AI that develops its own internal structure through continuous experience.

The project explores ideas such as:

- Spherical neural architecture
- Path-based memory
- Continuous learning
- Autonomous internal activity
- Long-term memory formation
- Audio, vision, and multimodal learning
- Self-organizing knowledge structures
