# SphereBrain v27

v27 separates the system into five responsibilities so the spherical core can grow without storing language directly.

## Architecture

1. **Encoder** — converts external text into a deterministic numeric stimulus.
2. **Core** — propagates only numeric state and learns by reinforcing traversed edges.
3. **Trace** — records the actual route before and after reinforcement as append-only experience.
4. **Decoder** — converts the converged numeric state into an inspectable external expression.
5. **Reflection** — re-enters past final states as new stimuli without rewriting the original trace.

## Important properties

- The Core does not receive words.
- Memory is represented by route strength, not by a text lookup table.
- Repeated experience makes the same route easier to select.
- Trace data remains observational and is never edited during reflection.
- Activation choice is normalized at every step.
- The v27 experiment is isolated from the existing prototype and can be evaluated safely.

## Run

```bash
python experiments/spherebrain_v27.py
```

Enter text one line at a time. Use `/reflect` to replay recent converged states.

Trace output is written to `data/v27_traces.jsonl` when the experiment is run directly.

## Test

```bash
pytest -q tests/test_spherebrain_v27.py
```
